# Anti-AI Writing

This is a mandatory pass on EVERY post. It cannot be disabled. Run this after the voice pass, before the quality gate.

The goal: make every post sound human. Not AI-generated. Not ChatGPT. Not robotic. A real person with real opinions wrote this.

---

## Banned Words

Never use these words in any post. Replace with simpler, natural alternatives:

| Banned | Use instead |
|--------|------------|
| delve | dig into, explore, look at |
| landscape | space, world, scene |
| foster | build, grow, encourage |
| crucial | important, key, matters |
| leverage | use, apply |
| comprehensive | full, complete, thorough |
| robust | strong, solid |
| revolutionize | change, shake up, transform |
| groundbreaking | new, first, big deal |
| game-changer | big shift, changes everything |
| cutting-edge | latest, newest, advanced |
| furthermore | also, and, plus |
| additionally | also, and |
| moreover | also, and |
| utilize | use |
| facilitate | help, enable |
| implement | build, do, set up |
| streamline | simplify, speed up |
| synergy | working together |
| paradigm | approach, model, way |
| ecosystem | system, space, community |
| innovative | new, creative |
| disruptive | different, challenging |
| scalable | grows with you |
| seamless | smooth, easy |
| empower | help, enable, let |
| holistic | full, complete |
| stakeholder | people involved, team |

## Banned Patterns

Never use these sentence structures or phrases:

### Opening patterns
- "In today's rapidly evolving..."
- "In an era where..."
- "As we navigate..."
- "It's worth noting that..."
- "I'm thrilled/excited to share/announce"
- "Let me share my thoughts on..."

### Structure patterns
- Triple adjective stacking ("innovative, scalable, and robust")
- Starting 3+ sentences with "This" in the same post
- Em dashes (—): allowed in moderation — they're part of the authentic voice for reframes and appositives. But max ~2 per post. Never stack them, and don't lean on "it's not X — it's Y" in every paragraph. If more than 2 appear, cut the weakest to a period or comma.
- The "it's not X, it's Y" reframe: fine ONCE, and best saved for the quoted-opinion line (it's a signature move). Banned as a repeated per-paragraph crutch.

### Filler/hedging
- "It goes without saying"
- "Needless to say"
- "At the end of the day"
- "When all is said and done"
- "The reality is"
- "The truth is"
- "Here's the thing"

### Engagement bait
- "Let that sink in"
- "Read that again"
- "I'll say it louder for the people in the back"
- "Unpopular opinion:" (when the opinion is actually popular)
- "Hot take:" (when it's room temperature)

### Weak verbs
- "serves as" → use "is"
- "stands as" → use "is"
- "marks a" → use "is"
- "represents" → use "is" or "means"
- "aims to" → use "will" or just state the action

### AI transition patterns
- Starting paragraphs with "However," "That said," "With that in mind,"
- "On one hand... on the other hand..."
- "While X, Y" as every other sentence

## What Good Human Writing Looks Like

- Starts mid-thought, not with setup
- Uses contractions (don't, won't, it's, that's)
- Has irregular rhythm (some long sentences, some fragments)
- Includes filler words humans actually use (look, honestly, yeah, basically)
- States opinions without hedging them
- Uses specific details, not vague generalizations
- Breaks grammar rules when it sounds better ("And that's fine." as a sentence)
- References specific things (names, numbers, dates) not "various stakeholders"

## The Check

For every post, go through:

1. **Word scan:** Does any banned word appear? Replace it.
2. **Pattern scan:** Does any banned pattern appear? Rewrite it.
3. **Structure scan:** Does the post follow a predictable AI template? Break it.
4. **Read-aloud test:** Would someone actually SAY this? If not, rewrite.
5. **Personality test:** Could this post have been written by anyone? If yes, it needs more voice.

If you fix something and it introduces a new banned pattern, fix that too. Repeat until clean.
