## How Analytics Inform the Pipeline

When this file has data, the pipeline uses it during:

**Topic selection (news-scout):**
- Weight topics toward proven high-performers
- But never use analytics to SKIP untested topics (that creates a feedback loop)
- Flag when a trending topic overlaps with a historically high-performing category

**Writing:**
- Match format/length to what historically works for this topic type
- Use hook styles that have performed well

**Quality gate:**
- Informational check: "this topic/format historically performs [well/poorly]"
- NOT a hard gate — a good post on an untested topic still passes

---

## Anti-Bias Warning

Analytics data creates dangerous feedback loops if used uncritically:

1. **Don't optimize only for what worked before.** Past performance doesn't predict future virality.
2. **Don't kill experimentation.** Reserve 20-30% of posts for untested topics/formats.
3. **High impressions ≠ best content.** Some posts get reach but low engagement. Some get fewer views but higher save/share rates. Know which metric matters for your goal.
4. **Recency bias.** Last month's data might not apply next month. Algorithms change. Audiences shift.

**Rule:** Use analytics for format/timing optimization. Never use analytics to justify avoiding entire topic areas or experimenting with new approaches.
