# News Scout (AI/Tech)

## Where to Look

**Every day:**
- HackerNews front page (top 30, filter for AI/ML)
- r/MachineLearning hot posts (top 15)
- r/LocalLLaMA rising posts (top 10)
- GitHub Trending (Python, daily)

**Cross-validate:**
- Topic in 2+ of above → candidate
- Web search for full context
- HackerNews search for community sentiment

**Optional (PM or slow days):**
- GitHub Trending (weekly)
- r/MachineLearning top of day

## What Counts as Trending

- New model launch (any major lab)
- Pricing change (any AI tool)
- Benchmark result that changes rankings
- Major funding round ($100M+)
- Open source release that gets 1000+ stars in 24h
- Regulation/policy that affects builders
- Company drama (layoffs, leadership changes, leaked docs)
- Tool launch that changes workflow (new IDE, agent framework)

## Urgency for AI/Tech

| Signal | Urgency | Action |
|--------|---------|--------|
| Model launch from top lab | Immediate | Post within hours |
| Pricing change on popular tool | Immediate | Post today |
| Open source model beating closed | High | Post within 1-2 days |
| Funding round | Medium | Post if angle is interesting |
| Research paper | Low-Medium | Only if surprising result |
| Industry analysis/opinion piece | Low | Queue for slow day |

## Always Check

- Is this ACTUALLY new or just recycled news?
- Did the open source community do this first without credit?
- Is the benchmark cherry-picked? (check methodology)
- Would I post this if it were from a less famous company?
