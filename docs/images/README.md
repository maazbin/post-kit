## Adding images

- Keep files under 5MB (GIFs under 3MB)
- Use descriptive filenames (e.g., `before-after-anti-ai.png`)
- Reference with relative paths: `![alt](docs/images/filename.png)`
- Prefer SVG for diagrams, PNG for screenshots, GIF for demos
