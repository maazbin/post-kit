# Quick Start

Get your content pipeline running in 5 minutes.

---

## 1. Install post-kit

Pick your tool:

**Kiro:**
- Go to kiro.dev/powers → search "post-kit" → click "Add to Kiro"
- OR inside Kiro: Powers panel → search "post-kit" → Install

**Claude Code:**
```
/plugin install post-kit@claude-plugins-official
```

**Cursor:**
- Settings → Rules/Skills → Add from GitHub → paste the repo URL

**Any other AI tool:**
- Clone or download the repo → open the folder in your tool

---

## 2. Start a conversation

Open a chat with your AI tool. It will automatically detect that you haven't set up yet and say:

> "Welcome to post-kit! Would you like guided setup or manual?"

Pick **guided**.

---

## 3. Answer the questions

The AI asks you about:
- Your niche
- Your voice/tone
- Your platforms
- Your content topics
- Whether you use visuals, memes, news scouting

Takes about 2-3 minutes. Answer honestly — this shapes your entire pipeline.

---

## 4. Start posting

After setup, just tell the AI what you want:

- **"Write a post about [topic]"** → full pipeline runs
- **"What's trending today"** → scouts for trending topics (if news-scout active)
- **"Roast [company/topic]"** → meme pipeline (if memes active)
- **"Help me improve my hooks"** → brainstorm skill

---

## That's it.

Your pipeline is live. Every post goes through: Research → Write → Voice Pass → Anti-AI Pass → Quality Gate → Output.

Want to change something later? Just say "help me improve my [voice/hooks/rules]" and the AI will brainstorm with you.
